K / ARCHIVE — Photo Compilation Website

HOW TO VIEW
1. Extract this ZIP file.
2. Open the kent_minimal_photo_compilation folder.
3. For best compatibility, run a local server from that folder:
   - Windows: open Terminal/Command Prompt in this folder and run: py -m http.server 8000
   - Then visit http://localhost:8000
   (If Python is unavailable, use VS Code's Live Server extension.)

CONTENTS
- index.html: minimalist black-and-white gallery
- media.json: media manifest
- assets/: photos and videos from the supplied archive

FEATURES
- Responsive photo grid
- Black-and-white visual treatment
- Filters for photos and videos
- Full-screen viewer with previous/next navigation
- Uses the media supplied in the original ZIP
